## 🗂️ ساختار پروژه

````
aiot-ssa.ir/
├── index.html        # صفحه اصلی
├── assets/
│   ├── css/          # استایل‌ها
│   ├── js/           # اسکریپت‌ها
│   └── images/       # تصاویر
└── README.md
````

> ⚠️ **نکته فونت:** این پروژه از فونت تجاری **پینار** استفاده می‌کند.  
> فایل فونت به دلایل کپی‌رایت در ریپوزیتوری قرار نگرفته.  
> برای اجرای محلی، فونت را تهیه و در مسیر `assets/fonts/` قرار دهید.
